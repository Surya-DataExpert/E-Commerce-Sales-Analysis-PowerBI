# E-Commerce Sales Analysis - Power BI

## Project Overview

This project analyzes e-commerce sales performance using Power BI and the Sample Superstore dataset.

The objective is to identify top-performing products, loss-making categories, and regional sales trends. The interactive dashboard provides insights to support business decision-making.

## Tools and Technologies

* Power BI
* Power Query
* Microsoft Excel
* DAX

## Dataset

Dataset: Sample Superstore

* Rows: 9,978
* Columns: 15
* Product Categories
* Sub-Categories
* Sales
* Profit
* Quantity
* Region
* Segment
* Product Names

## Data Cleaning and Preparation

The following data preparation steps were performed:

* Removed duplicate records
* Checked and handled missing values
* Verified data types
* Loaded the cleaned dataset into Power BI
* Used Power Query for data transformation

## Key KPIs

The dashboard tracks the following key performance indicators:

* Total Sales
* Total Profit
* Total Quantity
* Profit Margin

## Dashboard Analysis

The dashboard includes analysis of:

* Sales by Category
* Profit by Category
* Sales by Region
* Sales by Sub-Category
* Top 10 Products
* Loss-Making Sub-Categories

The dashboard can be filtered by Region, Category, and Segment.

## Key Insights

1. Technology generated the highest sales at approximately 0.84M.
2. Technology generated the highest profit at approximately 145K.
3. Furniture generated strong sales but relatively low profit at approximately 18K.
4. Tables, Bookcases, Supplies, and Fasteners were identified as loss-making sub-categories.
5. Phones and Chairs were among the top-selling products.
6. Regional, category, and segment filters allow users to explore the data interactively.

## Recommendations

* Increase focus on high-performing Technology products.
* Review pricing and discount strategies for Furniture.
* Investigate loss-making sub-categories.
* Promote top-selling products such as Phones and Chairs.
* Use regional insights for better resource allocation.
